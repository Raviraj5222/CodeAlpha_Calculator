Basic Calculator Web App

A simple and responsive Calculator built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations and supports both button clicks and keyboard input.

🚀 Features
➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
🖥️ Clean and user-friendly interface
⌨️ Keyboard support
🧹 Clear (C) and Delete (DEL) functionality
⚡ Real-time input and result display
❌ Error handling for invalid expressions
📂 Project Structure
calculator/
│
├── index.html     # Structure of the app
├── style.css      # Styling and layout
└── script.js      # Calculator logic
🛠️ Technologies Used
HTML5
CSS3 (Grid + Styling)
JavaScript (DOM Manipulation & Logic)
▶️ How to Run
Download or clone this repository
Open the folder
Double-click on index.html

OR

Open with Live Server in VS Code.

⌨️ Keyboard Controls
Key	Action
0–9	Numbers
+ - * /	Operations
Enter	Calculate result
Backspace	Delete last character
Esc	Clear display
⚠️ Note
This project uses eval() for calculation, which is fine for learning purposes but not recommended for production apps.
You can replace it with a safer expression parser for advanced usage.
